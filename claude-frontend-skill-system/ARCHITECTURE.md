# Skill architecture

These five skills are intentionally independent and composable. Invoke one directly for focused work, or combine them for a full design-build-audit-verify workflow.

Recommended full workflow:
1. `/frontend-design-system` — discover or establish the product's design language when needed.
2. `/frontend-design` — define and implement the interface direction.
3. `/frontend-engineering` — validate implementation quality and architecture.
4. `/frontend-ux-audit` — critique and refine the experience.
5. `/frontend-visual-testing` — verify the rendered result and interactions.

For small tasks, do not invoke all five. Use only the skills relevant to the requested scope.
